# ADR-0006: Private repository, no license for now

**Status:** Accepted · **Date:** 2026-07-27

## Context

Podium is developed in a private repository. A license only matters if the code is distributed.

## Decision

The repository stays **private** with **no license file**. Going public — and choosing a license —
is a separate future decision taken by the operator alone.

## Consequences

No public-use framing in the repo; adding a license later is a single additive change.
