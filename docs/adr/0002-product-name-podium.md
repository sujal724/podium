# ADR-0002: Product name — Podium

**Status:** Accepted · **Date:** 2026-07-27

## Context

The product needed a permanent name for the repo, CLI command, and identity (research decision 44
requires names be picked once and kept). Candidates: Baton, Maestro, Tutti, Podium.

## Decision

**Podium** — where the conductor stands and sees everything; matches the product's
mission-control, visibility-first identity. Repo `podium`, CLI command `podium`.

## Consequences

Name is frozen per the no-churn rule (research decision 44). Supersedes the working title
"agent-orchestrator". Records research decision 47.
